# @deepseek-ai/dsh-usage-dashboard

[English](README.md) | 中文

DeepSeek Harness Web 侧边栏的用量仪表盘：设置入口旁的一个底部操作，把会话列表保留的投影值——持久化的 `tokenUsage` 四个桶与整日志的 `sessionStats` 计数——折叠为跨会话总量。侧栏展开时触发器渲染为紧凑行，收起时渲染为栏内圆形按钮；两者打开同一个模态对话框。该插件不发起 RPC，除对话框可见性与趋势时间尺度选择外不持有任何状态：所有读取都经由标准 `useSessions` hook 走运行时已维护的列表镜像。本仓库与 deepseek-harness monorepo 的关系记录在 [REPO.md](REPO.md)。

## 展示内容

- **统计卡片。** 总 token、计费输入、输出、缓存命中占比、缓存读/写、轮次、步数、LLM 与工具耗时、平均解码吞吐。数值为零或不可用的卡片整张省略。
- **用量趋势图。** 每个会话按真实 `updatedAt` 位置放一根柱，以所选时间尺度（近 7 天 / 近 30 天 / 全部）内最高的会话为基准缩放，并带坐标轴标注：y 轴刻度为 0 / 半值 / 最大值（紧凑 token 形式），x 轴标签标注尺度窗口的起止日期。
- **按会话表格。** 按更新时间倒序：会话、最近计费模型、轮次/步数与输入/输出/总计三个 token 列。会话未提供 `sessionStats` 值时轮次/步数保持空白（`—`），未提供 `tokenUsage` 值时模型格保持空白。

## 数据语义

所有数字都是整日志持久化数值，分页与压缩不会改变它们。输入是三个互斥的提示词侧桶（`uncachedInputTokens`、`cacheReadTokens`、`cacheWriteTokens`）之和；总计再加上 `outputTokens`。模型标签是最近一条 `request/header` 的提供方模型 id，last-wins，因此会话中途切换模型后总量标注的是最新计费路由。趋势图按每个会话的真实 `updatedAt` 位置折叠总量；时间尺度只过滤并重新缩放这份折叠。

## 模型体验

无。仪表盘在浏览器中渲染已记录的投影值；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **范围限于在线会话列表** — 总量只折叠运行时维护的列表镜像，列表之外的会话（已归档或未加载的工作区）不计入。趋势图没有按天分桶，也没有会话内部的时间序列。
- **标签上线前完成 checkpoint 的会话没有模型标签** — 模型格读取 `tokenUsage` 投影的最新 `request/header`，因此在标签上线前最后一次 checkpoint 的会话，其模型格会保持空白，直到会话被打开（尾部重放会重折出标签）或下一次 checkpoint。token 总量不受影响。
